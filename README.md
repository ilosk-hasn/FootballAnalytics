# FootballAnalytics v2.0

تطبيق Windows لتحليل مباريات كرة القدم، مطوّر انطلاقاً من المشروع v1.0. يحتفظ بواجهة CustomTkinter وقاعدة SQLite وتحليل Poisson واستيراد/تصدير CSV وExcel.

## الجديد في v2.0

- لوحة قابلة للفتح والإغلاق لجلب السجل السابق للفريقين المحددين.
- طريقة الاستيراد `both`: حتى 20 مباراة مكتملة سابقة لكل فريق (حتى 40 مباراة فريدة قبل إزالة التكرار).
- مصدر النتائج والتفاصيل: واجهات ESPN العامة لكرة القدم. يطابق أسماء الفرق في المسابقة المختارة، ويجلب موجز المباراة عند توفره.
- تحفظ تفاصيل الاستجابة المتاحة، مثل الإحصاءات والتشكيلات والغيابات والبطاقات إذا أعادها المصدر، داخل حقل الملاحظات بصيغة JSON مع معرّف المباراة والمصدر.
- لا تُستنتج قيم غائبة. نتيجة الشوط الأول تقبل قيمة فارغة إذا لم يرسلها المصدر. تُعرض أخطاء الشبكة أو أسماء الفرق الملتبسة وسجلات التغطية الناقصة للمستخدم.
- تُتجاوز المباراة الموجودة مسبقاً عند إعادة الاستيراد.
- استيراد CSV وExcel يحفظ الصفوف المقبولة على دفعة واحدة مع الحفاظ على الأخطاء لكل صف.

التغطية تختلف حسب الدوري والمباراة. لا تضمن ESPN وجود الاستحواذ أو الغيابات أو التشكيلة أو الشوط الأول لكل سجل. لا تُعامل البيانات الناقصة كصفر. يحتاج الاستيراد لاتصال إنترنت؛ واجهات المصدر عامة وغير رسمية وقد تتغير أو تقيّد الطلبات.

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث.
2. افتح PowerShell في مجلد `FootballAnalytics_v2`.
3. نفّذ:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   python main.py
   ```

4. من الشريط الجانبي اختر **استيراد / تصدير**، ثم افتح لوحة **استيراد سجل الفريقين السابق**. أدخل رمز المسابقة واسمَي الفريقين. مثال رمز المسابقة `eng.1`؛ الرموز المتاحة تختلف باختلاف تغطية المصدر.

## البيانات

تنشأ قاعدة البيانات في `data/football_analytics.db`. انسخ هذا الملف احتياطياً للاحتفاظ ببياناتك. بيانات الاستيراد التفصيلية محفوظة في ملاحظات المباراة بصيغة JSON. لا يضمن التحليل الرياضي نتيجة المباراة؛ احتمالات Poisson تقديرات مبنية على النتائج المتاحة.

## الاختبار والتغطية

شُغّلت ستة اختبارات محلية للتحقق من تطابق قيم سجل الفريق وميزات التدريب مع الحساب السابق، وثبات مخرجات التحليل، ومعالجة الاستيراد الدفعي، وطلب موجز واحد عند تداخل سجلات الفريقين، وتجاوز تفاصيل المباريات الموجودة مسبقاً. شُغّل أيضاً فحص ترجمة ملفات Python. لم يُنفذ استيراد حي؛ ذلك يتطلب اتصال ESPN وتوافر الدوري والفريقين.

لتشغيل التحقق محلياً من مجلد `FootballAnalytics_v2`:

```powershell
python -m unittest discover -s tests -v
python -m compileall -q core database services gui main.py
```
