# FootballAnalytics

تطبيق Windows لتحليل مباريات كرة القدم، مبني على السكربت الأصلي `skripte.py`.

## المزايا الحالية
- واجهة Desktop باستعمال CustomTkinter.
- قاعدة بيانات SQLite محلية.
- إدخال وتعديل وحذف المباريات.
- تخزين الفريقين والبطولة والتاريخ ونتيجة الشوط الأول والنتيجة النهائية.
- تحليل احتمالات 1X2 وOver/Under وBTTS والنتائج الصحيحة باستعمال Poisson.
- تصدير واستيراد CSV وExcel.
- سجل للمباريات مع إمكانية حذف السجلات.
- طبقة Machine Learning اختيارية (Random Forest) لا تعمل إلا عند وجود بيانات كافية، ولا تستبدل نموذج Poisson عند نقص البيانات.

## التشغيل على Windows
1. ثبّت Python 3.11 أو أحدث.
2. افتح PowerShell داخل مجلد المشروع.
3. أنشئ بيئة افتراضية:
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
4. ثبّت المتطلبات:
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
5. شغّل التطبيق:
   ```powershell
   python main.py
   ```

## قاعدة البيانات
يُنشأ الملف `data/football_analytics.db` تلقائياً عند أول تشغيل. لا تحذف هذا الملف إذا أردت الاحتفاظ ببياناتك.

## ملاحظات منهجية
- نموذج Poisson إحصائي، وليس نموذج تعلم آلي.
- يتطلب التحليل بيانات تاريخية مناسبة. النتائج القليلة قد تنتج تقديرات غير مستقرة.
- لا توجد دقة مضمونة للتوقعات الرياضية. استخدم تقييم Brier Score وLog Loss عند توفر نتائج فعلية.
- طبقة Random Forest اختيارية وتجريبية، وتحتاج عدداً كافياً من المباريات ذات النتائج المعروفة.
